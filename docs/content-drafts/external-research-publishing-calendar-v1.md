# JapanMedAI 外部高价值选题内容发布排期 V1.0

状态：Draft｜仅内部排期｜未发布｜2026-10-15

目标：把已完成的10篇长文、10条微信问一问、20条短视频脚本，拆成连续10天的多平台内容矩阵。外部平台负责获客与触达，JapanMedAI负责承接、沉淀与转化。

## 统一原则

- 不复制厚朴方舟、盛诺一家、丁香医生原文、病例身份或疗效叙事。
- 所有医学事实以日本官方资料、监管资料、医院官方信息、指南或原始研究重新核对。
- 不写“日本一定能做”“海外专家推翻原方案”“成功治愈”等结果承诺。
- 同一母题跨平台只改表达，不改变医学结论。
- 微信问一问：100–300字，直接回答，不强转化。
- 短视频：0–3秒问题；3–12秒答案；12–45秒判断清单；45–60秒边界。
- 微博：150–300字，强调一个反常识结论。
- X/Facebook：海外华人版，句子短、结论先行、避免中国本地化术语。
- 公众号：1200字左右，作为中文深度主稿。

## 发布顺序建议

每天建议按以下顺序执行：
1. 上午：微信问一问（先抢搜索问题位）
2. 中午：微博 / X / Facebook 简版
3. 下午：短视频A
4. 晚上：公众号长文
5. 次日或隔6–12小时：短视频B，换一个切口，不重复标题

## 10天后的二次利用

- 表现前3名：进入官网S级候选池，评估是否新增独立决策页或强化现有Q&A。
- 咨询率高但阅读一般：优先做第二轮短视频与FAQ，不追求长文阅读量。
- 阅读高但咨询低：保留做SEO/GEO流量词，不硬做转化。
- 收藏/转发高：制作“一页清单图”或PDF工具。
- 评论区反复出现的新问题：进入JapanMedAI患者问题雷达。
