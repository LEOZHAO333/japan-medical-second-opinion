# JapanMedAI 300页 Search Console 分层规则 V1.0

目的：用真实 Google Search Console 数据决定 300 个核心医疗 Q&A 页的保留、强化、合并与降权，避免凭感觉删除或 noindex。

## 观察窗口

- 新页面上线后前 28 天：只观察，不做 noindex/合并。
- 29–60 天：允许优化标题、Meta、首屏答案、内链权重。
- 61–90 天：允许进入候选合并池。
- 90 天以上：结合曝光、点击、平均排名、查询重叠和商业价值做最终动作。

## 四类动作

### KEEP 保留
满足任一：
- 28天有稳定曝光且查询与页面搜索意图一致；
- 已有点击或平均排名进入前30；
- 是 P0/P1 决策页、监管页、资料准备页或商业承接页。

动作：保持 index,follow + self-canonical；只做正常维护。

### STRENGTHEN 强化
典型条件：
- 曝光 >= 50 且 CTR < 2%；
- 平均排名 8–30；
- 查询高度匹配，但标题/摘要点击力弱；
- AI/GEO价值高但站内权重不足。

动作优先级：Title/Meta → 直接回答 → 官方证据 → Hub/首页内链 → FAQ。

### MERGE 合并候选
必须同时考虑：
- 60–90天以上持续低曝光；
- 与另一页面主要查询高度重叠；
- 两页解决的是同一个决策问题而非互补问题；
- 合并后不损失重要监管/医疗边界。

动作：确定主URL；将有价值内容并入主页面；旧URL做301，不直接删除。

### DOWNRANK / NOINDEX 降权候选
仅用于长期没有独立搜索价值的辅助页，且必须满足：
- 至少90天真实数据；
- 几乎无曝光/点击；
- 无独立查询意图；
- 不是商业入口、监管状态、风险边界、资料准备或核心决策页；
- 与更强主页面高度重复。

默认不执行 noindex，除非数据证据充分。

## Cannibalization 判定

同一查询下两页同时获得显著曝光时：
- 若意图不同：保留，强化差异化标题/直接回答；
- 若意图相同且排名互相波动：进入 MERGE 候选；
- P0/P1 页面优先作为主URL。

## 300页层级

- P0：首页直接支持的10个核心决策页。
- P1：各Hub核心S级页面，承担高价值决策与转化。
- P2：其余长尾问题页，承担搜索覆盖与知识图谱扩展。

## 医疗内容保护规则

任何合并、降权或删除动作都不能仅凭低流量执行。以下页面默认保护：批准状态、适应证、风险/禁忌、海外接诊条件、资料准备、药品监管、研究/临床试验边界、BNCT/iPS真实可及性。

## 每轮输出

每次导入GSC数据后，必须生成：
1. KEEP 清单
2. STRENGTHEN 清单
3. MERGE 候选清单
4. DOWNRANK 候选清单
5. 查询互抢清单
6. P0/P1排名变化清单

在完成全量QA前，不直接修改正式站。
