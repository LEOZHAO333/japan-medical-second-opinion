# 二次会诊咨询路径 V1｜审阅与验收清单（2026-10-26）

## 已实现的范围
- `/second-opinion/` 首屏保持“3分钟预评估”为第一入口，新增“已有资料：了解咨询方式”锚点进入已有 `#contact`。
- 自测结果区新增可见的联系入口，避免唯一链接隐藏于折叠栏内；原有“复制咨询开场信息”、微信二维码及邮件说明保持原样。
- `/checkup/` 首屏按三类意图分流：已有资料→二次会诊咨询；资料不齐→既有无上传的资料自查；还在了解→已经发布的二次会诊100问。
- 移动端三入口单列且各自点击面积至少48px。
- 仅通过现有 `JMAIAnalytics` 记录无医疗内容的固定CTA ID；原有业务事件表不变，无新外部服务、无新增第三方权限、无上传或联系表单。

## 审核重点
- [ ] Claude-2 医学边界：二次意见不是诊断/治疗承诺；资料审阅或提交不等于医院接受患者。
- [ ] Claude-3 内容与SEO：只是现有链接入口调整，没有新增相似专题页、未改变canonical/schema。
- [ ] S0/CI：检查新入口href、语义标签、JS监听有效、相应站点脚本和构建。
- [ ] 桌面/手机：首屏按钮无溢出，自测结果可见，三个分流路径能到达真正的页面。
- [ ] 转化隐私：点击统计不记录病种、患者姓名、联系方式、问卷答案、报告或邮件正文。
- [ ] 业务人工验收：新增入口通向现有联系方式，不保证单次咨询一定获安排；最终需要Founder审核发布。
