## 服务边界

JapanMed AI 用于医疗信息整理和跨境医疗路径参考，不进行医学诊断、患者资格认定、处方或治疗方案制定。所有临床结论、收治决定及治疗建议均由接诊医疗机构的执业医师独立作出。

BNCT、iPS、再生医疗、精准放疗及其他新疗法必须区分已获批治疗、临床试验、研究与个案治疗状态，不应被描述为对所有患者普遍适用。

如出现呼吸困难、意识障碍、持续大出血、快速瘫痪或其他急症，应立即在所在地就医，不应等待海外意见。
